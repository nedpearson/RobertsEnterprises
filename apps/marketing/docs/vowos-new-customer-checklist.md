# VowOS New Customer Checklist

## 1. Initial Provisioning
- [ ] Create Supabase tenant project.
- [ ] Configure database schema and RLS (Row Level Security) policies.
- [ ] Set up Edge Functions for background tasks.
- [ ] Provision AI Action Center environments.

## 2. Configuration
- [ ] Configure store locations and tax rates.
- [ ] Set up user roles (Owner, Manager, Associate, Seamstress).
- [ ] Initialize universal product catalog categories.
- [ ] Configure integer-cents billing settings for financial accuracy.

## 3. Integrations
- [ ] Connect payment gateway.
- [ ] Configure SMS/Email messaging templates for appointment reminders.
- [ ] Set up accounting export configurations.

## 4. Hardware Setup (If applicable)
- [ ] Validate POS hardware compatibility.
- [ ] Test receipt printer and barcode scanner integrations.
