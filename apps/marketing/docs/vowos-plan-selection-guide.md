# VowOS Plan Selection Guide

## VowOS Essentials
**Best For:** Single-location boutiques looking to modernize their operations.
- Universal Product Catalog
- Standard Point of Sale (POS)
- Integer-cents financial engine
- Basic appointment booking
- Supabase secure cloud infrastructure

## VowOS Professional
**Best For:** High-volume or multi-location retailers needing advanced workflows.
- *Everything in Essentials, plus:*
- AI Action Center (Proactive task management)
- Advanced alterations tracking
- Custom user roles and permissions
- Automated SMS/Email communications

## VowOS Enterprise
**Best For:** Large regional chains or franchise operations.
- *Everything in Professional, plus:*
- Dedicated Supabase instance / Custom data residency
- API access for custom integrations
- Advanced commission structures
- White-glove data migration and onboarding

## Recommendation Matrix
| Feature Need | Plan |
| :--- | :--- |
| Single store, simple POS | Essentials |
| Multi-store, needs AI task management | Professional |
| API access, custom integrations | Enterprise |
